Why slow beats fast

🐢 Patience, engineered

1200/3500 ms turn-taking envelope with semantic barge-in. Pauses are waited through — backchannel murmurs never cut the agent off.

👂 Hears drug names right

Per-stage keyterm narrowing boosts clinic names, then drugs like Metoprolol succinate — switchable live, no reconnect.

🧾 Proof, not promises

Nothing books without a read-back and an explicit “yes”. Every call ends in an HMAC-signed receipt the family can verify.

Under the hood (all AssemblyAI)

  • Voice Agent API — one WebSocket: STT + turn detection + LLM + TTS.
  • Patient turn-taking — tuned envelope + semantic interruption, switchable live.
  • Dynamic keyterms — vocabulary narrows per stage (clinic → drugs).
  • 5 function/HTTP tools — availability, transactional booking, meds, teach-back, receipts.
  • Twilio — number, SIP trunk, SMS receipts for US handsets.

Where this goes

  1. Durable backend — Postgres replacing the file store.
  2. Older-adult pilots — lock tone with real callers.
  3. Clinic pilot — priced per confirmed visit; caregiver plan.
  4. Expansion — refills, scam warnings, WhatsApp intake.
