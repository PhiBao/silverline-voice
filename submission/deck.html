Technical depth — all AssemblyAI

Five mechanisms, one loop.

  • Patient turn-taking — 1200/3500 ms envelope + semantic barge-in; switchable live via session.update
  • Dynamic keyterms — vocabulary narrows per stage (clinic → drugs), no reconnect
  • 5 function + HTTP tools — availability, transactional booking, meds, receipts
  • Single-use token mint — API key never reaches the browser; session.end hygiene
  • Real phone path — Twilio SIP trunk → sip.eu.assemblyai.com (EU accounts 503 on the US ingress — found live)
  • Supabase Postgres — durable bookings/receipts; server-side caller memory
